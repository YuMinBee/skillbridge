# 웹 Claude 캡처 (발표 슬라이드 ①, 담당 이승연)

목적: "웹 Claude에 그냥 물으면 여기까지"를 실제 화면으로 보여 준다. 같은 글을 우리 서비스에도 넣어 시연한다.

## 넣을 것

1. https://claude.ai → **새 채팅** (이전 대화·프로젝트·메모리 없이)
2. 아래 문장을 그대로 쓰고, 한 줄 띄운 뒤 [demo_resume.md](demo_resume.md)의 `---` 아래 본문 전체를 붙여 넣는다.

```
내 역량 분석하고 과제 추천해 줘. 백엔드 개발자로 취업하려고 하고, 들을 만한 교육과정도 알려 줘.
```

3. 답이 끝나면 화면 전체를 캡처 → `web_1.png`
4. **새 채팅**으로 2~3을 두 번 더 → `web_2.png`, `web_3.png` (같은 문장, 같은 본문)
5. 답 원문도 복사해 `web_1.txt` ~ `web_3.txt`로 저장 (슬라이드에서 인용할 때 씀)

## 캡처에서 표시할 것 (빨간 네모)

- 자소서에 **없는 성과·경험**을 강점이라고 한 곳 (예: 본문에 숫자가 없는 경험에 "성과를 냈다")
- **실제로 있는지 모르는 교육과정 이름·기관** (고용24에서 검색해 없으면 표시)
- 3번 답이 **서로 다른 곳** (강점 순서, 부족한 역량, 추천 과정)
- 꾸민 말만 있는 경험(3번 경험)을 강점으로 칭찬한 곳

## 주의

- 실제 개인 자소서를 쓰지 않는다. 이 본문은 합성이다.
- 캡처에 이메일·이름 등 계정 정보가 보이면 가린다.
- 무료 계정이면 모델 이름도 캡처에 보이게 한다(Sonnet 등). 공정성 질문 대비.
