# 시연 대본 (5분)

> 한 문장 요약: **"공고는 입사 문턱만 알려줍니다. 역량다리는 기업이 입사 후 실제로 쓰는 역량까지 받아서, 취준생이 붙는 준비와 일할 준비를 함께 하게 합니다."**

준비
- 주소: 배포 URL(`python infra/deploy.py --yes` 출력) 또는 로컬 `.\tasks.ps1 run` → http://localhost:5173
- 시작 전에 오른쪽 위 **초기화**를 누릅니다.
- 오른쪽 위 배지가 `BEDROCK · 과정 LIVE · 시장 LIVE+SAMPLE`인지 확인합니다.
- **백업:** 인터넷이나 SSO가 끊기면 `.env`에서 `BEDROCK_MOCK=1`로 바꾸고 재시작합니다. 같은 화면이 규칙 엔진으로 동작합니다. 녹화 영상도 준비해 둡니다(`docs/demo.mp4`).

## 예상 질문

| 질문 | 답 |
|---|---|
| 기업 데이터는 진짜인가요? | 기업 A·B·C와 지원자는 가상입니다. 공고 1만 1천 건과 훈련과정은 실데이터입니다(잡알리오·고용24). 화면 배지에 표시돼 있습니다. |
| 정답 라벨은 누가 만들었나요? | 1차는 AI 보조 초안, 2차는 팀원이 따로 붙여 κ로 일치도를 쟀습니다(eval/report.md 5절 · ⚠ 2차 라벨 전이면 "진행 중"이라고 답할 것). |
| LLM이 과정을 지어내지 않나요? | 과정은 카탈로그에 있는 것만 냅니다. LLM은 설명만 쓰고, 인용 번호가 근거 목록 밖이면 템플릿으로 바꿉니다. |
| 비용은? | 진단 1회에 Bedrock 호출 6~9번, 몇 원 수준입니다. 공고 추출은 캐시해서 같은 공고는 다시 부르지 않습니다. OpenSearch Serverless 대신 S3 Vectors를 써서 상시 과금이 없습니다. |
| 이게 에이전트인가요, 파이프라인인가요? | 둘 다입니다. 진단은 순서가 중요해서 단계를 고정하고 trace로 다 보여줍니다(재현·폴백이 투명). 자유 질문은 학습 코치 에이전트가 도구 5개 중 스스로 골라 부릅니다. |
| 공개 주소인데 누가 기업 기준을 망가뜨리면요? | 기업 콘솔 수정은 방문자별 샌드박스에만 저장되고 원본은 안 바뀝니다. 24시간 뒤 사라집니다. |
| 누가 반복 호출하면 비용은요? | IP당 분당 8회, 인스턴스당 시간당 60회 Bedrock 상한(넘으면 규칙 엔진으로 전환), Lambda 동시 실행 3개입니다. |
| 정답셋 30건이면 작지 않나요? | 그래서 부트스트랩 95% 신뢰구간을 냈습니다. 유의한 것(오탐 감소, 갭 커버 차이)과 아직 확정 못 한 것(공고 F1)을 구분해서 적었습니다. |
| AI가 만든 정답으로 AI를 채점한 것 아닌가요? | 1차 라벨은 AI 초안이 맞고, 그래서 팀원이 원문만 보고 따로 2차 라벨을 붙여 κ를 냈습니다(⚠ 2차 라벨 완료 후에만 이렇게 답할 것). 지원자 정답은 생성할 때 정한 값이라 모델과 무관합니다. |
| 이력서가 해외 리전으로 나가나요? | 추출·설명 모델은 `global.` 교차 리전 추론 프로필이라 서울 밖에서 처리될 수 있습니다(서울 리전에서 최신 Claude는 이 프로필만 열려 있음). 그래서 모델에 보내기 **전에** 서울 리전의 Guardrails와 정규식으로 이름·연락처·주소 등 개인정보를 먼저 가리고, 원문은 저장하지 않습니다. 임베딩(Titan)·지식베이스·DB는 서울 리전입니다. 운영에서는 `MODEL_ID`를 `apac.` 프로필로 바꿔 아시아 안에서만 처리하게 할 수 있습니다(이 경우 품질은 재평가 필요). |
| 기업 D(토스증권)는 토스가 등록한 건가요? | 아닙니다. 공개된 채용 공고(지원 기준)와 같은 회사 엔지니어의 기술 블로그(실무 기준)로 우리가 재구성했고, 스킬마다 출처를 화면에 붙였습니다. 블로그 기술은 중요도를 몰라 전부 '우대'로 뒀습니다. |
| 왜 공공기관 공고인가요? | 공개 API로 1년 치 전수를 받을 수 있는 유일한 공고원이기 때문입니다. 민간 AI 직무는 샘플로 따로 표시했습니다. |
