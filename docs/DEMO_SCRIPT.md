- 백업: `BEDROCK_MOCK=1`로 재시작, 녹화 영상 `docs/demo.mp4`.

## 예상 질문

| 질문 | 답 |
|---|---|
| 웹 Claude와 비교가 공정한가요? | 같은 Bedrock Claude 모델에 같은 이력서와 같은 요청 문장을 넣었습니다. 차이는 검색·인용 검증·규칙 점수·거부, 즉 시스템뿐입니다(`eval/trust/baseline_web.py`). |
| STAR를 LLM에 시킨 것 아닌가요? | LLM은 칸에 들어갈 원문 문장을 고르기만 합니다. 원문에 없는 문장이면 코드가 버리고, 점수는 규칙으로 계산합니다. 그래서 같은 입력이면 같은 결과가 나옵니다. |
| 정답은 누가 만들었나요? | 합성 경험 단락에 팀원 두 명이 따로 라벨을 달고 일치도(κ)를 냈습니다. 시스템과 사람의 일치도를 사람끼리의 일치도와 나란히 보여 드렸습니다. |
| 표본이 작지 않나요? | 그래서 모든 숫자에 95% 신뢰구간을 붙였고, 구간이 겹치는 차이는 "개선"이라고 하지 않았습니다. |
| 왜 이 임베딩·청크 설정인가요? | dev 정답셋으로 조합을 비교해 골랐고, test는 마지막에 한 번만 돌렸습니다(⑦ 표). |
| 비용은? | 요청마다 토큰과 금액을 화면에 표시합니다. 요청 예산을 넘으면 남은 단계를 건너뜁니다. 상시 과금 리소스는 없습니다. |
| 오래 걸리면요? | 작업으로 접수해 서버에서 끝까지 돕니다. 브라우저를 닫았다 열어도 결과가 남아 있습니다. |
| 이력서가 해외로 나가나요? | 모델에 보내기 전에 서울 리전 Guardrails와 정규식으로 개인정보를 가리고, 원문은 저장하지 않습니다. |
